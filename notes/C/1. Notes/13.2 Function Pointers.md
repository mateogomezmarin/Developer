
**C Function Pointers**
A **function pointer** stores the **address of a function**, allowing you to call or pass that function indirectly.

Declaration
```c
int (*ptr)(int, int);
```

`ptr` → pointer to a function that takes two `int`s and returns an `int`.

### Assign & Call

```c
ptr = add;       // same as: ptr = &add

ptr(5, 3);       // same as: (*ptr)(5, 3)
```

**Example**
```c
int add(int a, int b) {
    return a + b;
}

int main() {
    int (*ptr)(int, int) = add;

    printf("%d", ptr(5, 3));
}
```

**Callback**
A function pointer can be passed to another function:

```c
void greet(void (*func)()) {
    func();
}

greet(greetMorning);
```

This is called a **callback**.

**Array of Function Pointers**

You can store multiple functions in an array:

```c
void (*operations[3])(int, int) = {
    add, subtract, multiply
};

operations[0](10, 5);  // add
operations[1](10, 5);  // subtract
```

Useful when you need to **choose which function to execute at runtime**, e.g. menus or calculators.

> **Key idea:** A normal function is called directly; a function pointer lets you store, pass, and choose functions dynamically.
