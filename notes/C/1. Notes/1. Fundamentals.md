This is a brief introduction to C fundamentals.

**Difference between C and C++**
- C++ was developed as an extension of C, and the syntax is often similar
- C is mainly a procedural language (you build programs with functions)
- C++ supports classes and objects (often used for object-oriented programming)

**Hello World Program**
```
#include <stdio.h>  
  
int main() {  
  printf("Hello World!");  
  return 0;  
}
```

**Creating and running a file**
- We create the file in VS Code and save with *Ctrl S*

In the VS Code terminal, make sure you're in the folder containing `hello.c`, then compile using gcc

```
gcc hello.c -o hello  
```

This is compiling the program, afterwards, we use:

```
./myfirstprogram
```

The terminal should display

```
Hello World!

```


**Lets break down the Helloworld code and understand what each part does:**

```
#include <stdio.h>

int main() {
  printf("Hello World!");
  return 0;
}
```

- Line 1: *#include <stdio.h>* includes the contents of the stdio.h library.
- Line 2: Blank space ignored by C
- Line 3: *main()* is a special function. Your program starts running here. Any code inside the curly brackets {} will be executed.
- Line 4: *printf()* is a function used to output (print) text to the screen.
- Line 5: *return 0* ends the main function and sends the value back to the operating system.
- Line 6: *}* ends the main() function.

Note: Every C statement ends with a semicolon.

- When you want to print text, the text must be wrapped in double quotes `""`
- You can use as many `printf()` functions as you want.

**However,** note that it does not insert a new line at the end of the output:

```
#include <stdio.h>  
  
int main() {  
  printf("Hello World!");  
  printf("I am learning C.");  
  printf("And it is awesome!");  
  return 0;  
}
```

- `\n` tells the program to move the cursor to the beginning of the next line.
-  `\t` Inserts a horizontal tab

**Comments in the code:**

Single-line comments start with two forward slashes `//`
Multi-line comments start with `/* and end with */`
