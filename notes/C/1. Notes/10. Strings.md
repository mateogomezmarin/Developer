C does not provide a basic *String* type like other programming languages.

Instead we use the char type and create an array of characters:
```
char text[] = "This is a sample text";
```
We use the s format specifier for printing.
```
printf("%s", text)
```
Since strings are actually arrays of characters in C you can access them through the index.
```
printf("%c",text[0]) // will print the first character "T"
//Note we use c as the format specifier to print a single character.

```
**Cases of use**
```
char greetings[] = "Hello World!";  
greetings[0] = 'J';  
printf("%s", greetings);  
// Outputs Jello World! instead of Hello World!

//looping through a string
char carName[] = "Volvo";  
int length = sizeof(carName) / sizeof(carName[0]);  
int i;  
  
for (i = 0; i < length; ++i) {  
  printf("%c\n", carName[i]);  
}
```


Because strings must be written within quotes, C will misunderstand this string, and generate an error, we need to add \ before special characters:
```
char txt[] = "We are the so-called "Vikings" from the north."; //ERROR
char txt[] = "We are the so-called \"Vikings\" from the north." //CORRECTED VERSION adding the backslash \
```

**String functions**
Requires:
```
#include <string.h>
```

| Function   | Purpose                       | Example              |
| ---------- | ----------------------------- | -------------------- |
| `strlen()` | String length (excludes `\0`) | `strlen(str)`        |
| `strcat()` | Joins strings                 | `strcat(str1, str2)` |
| `strcpy()` | Copies a string               | `strcpy(str2, str1)` |
| `strcmp()` | Compares strings              | `strcmp(str1, str2)` |
 **strlen() vs sizeof()**
```c
char str[] = "Hello";

strlen(str);  // 5
sizeof(str);  // 6 → includes '\0'   c adds a space at the end of the string to indicate the end

```

`sizeof` = memory size in bytes
`strlen` = actual string length

**strcpy and strcat**
```c
char str1[20] = "Hello World!";  
char str2[20];  //size should be copied
char str3[2] = !"!!"
// Copy str1 to str2 IMPORTANT
strcpy(str2, str1);
// Concatenating strings  
strcat(str1, str3); //Returns Hello World!!!
  
// Print str2  
printf("%s", str2);

```
**strcmp**
Return
```c
strcmp(str1, str2) == 0  // strings are equal
strcmp(str1, str2) != 0  // strings are different
```

> **Remember:** C strings are character arrays ending with `\0`.
