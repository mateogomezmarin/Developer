Basic syntax
```c
returnType functionName (parameter1, parameter2, parameter3) {  
  // code to be executed  
}
```
Basic example:
```c
void calculateSum(int x, int y) {  //Same as java
  int sum = x + y;  
  printf("The sum of %d + %d is: %d\n", x, y, sum);  
}  
  
int main() {  
  calculateSum(5, 3);  
  calculateSum(8, 2);  
  calculateSum(15, 15);  
  return 0;  
}
```

**Scope** = where a variable can be accessed.

- **Local scope:** Variable declared inside a function/block → only accessible there.
    
- **Global scope:** Variable declared outside functions → accessible from any function.
    
- A local variable with the same name as a global variable **hides** the global one inside that scope.
    
- Avoid unnecessary global variables because any function can modify them.
    

```c
int x = 5;        // global

void func() {
    int x = 10;   // local → hides global x
}
```

**Math functions**
```c
#include <math.h>  //VERY IMPORTANT
printf("%f", sqrt(16)); //Square root

//The `ceil()` function rounds a number upwards to its nearest integer, and the `floor()` method rounds a number downwards to its nearest integer, and returns the result:
printf("%f", ceil(1.4));  //Rounds up to 2
printf("%f", floor(1.4)); //Rounds up to 1

printf("%f", pow(4, 3)); // 4³
```

  
Here is a simple example that uses an `inline` function:
Usefull for small functions.

**Inlince functions**
```c
#include <stdio.h>  
  
inline int add(int a, int b) {  
  return a + b;  
}  
  
int main() {  
  printf("%d", add(5, 3));  
  return 0;  
}

// Here, the compiler might replace add(5, 3) with the code 5 + 3 directly - saving the time it would take to call a separate function.

```

**Recursion**
Countdown example
```c
void countdown(int n);

int main() {
  countdown(5);
  return 0;
}

void countdown(int n) {
  if (n > 0) {
    printf("%d ", n);
    countdown(n - 1);
  }
}
```
