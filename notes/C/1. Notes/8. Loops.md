Loops can execute a block of code as long as a specified condition is true.

**While loop**
```
while (condition){
// code block to be executed
	}

int i = 0;  
  
while (i < 5) {  
  printf("%d\n", i);  
  i++;  
}

// The Do/While Loop

do {  
  _// code block to be executed_}  
	while (_condition_); //loop 
```

**For loop**
```
int i;
for(i = 0; i++, i < 5){
		print("%d\n", i);
	}
```

**Break / Continue**
- `break` = stop the loop completely.
- `continue` = skip this round, but keep looping.
