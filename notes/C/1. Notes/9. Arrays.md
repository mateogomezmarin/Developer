Arrays are used to store multiple values in a single variable, instead of declaring separate variables for each value.

To create an array, define the data type (like `int`) and specify the name of the array followed by **square brackets []**.

To insert values to it, use a comma-separated list inside curly braces, and make sure all values are of the same data type:

```
int myNumbers[] = {25, 50, 75, 100}; 

myNumbers[0] = 33; //We modified the first array element, // accesed via index

printf("%d", myNumbers[0]); //printed with the format modifier of the exam
```

>It is important to note that all elements in an array **must be of the same [data type](https://www.w3schools.com/c/c_data_types.php)**.


**Setting array size**
A common way of creating arrays is to specify the size first and then introduce the elements.

```
//Create array with size 4 
int myNumbers[4];

//Introduce elements in the array
myNumbers[0] = 22
myNumbers[1] = 35
myNumbers[2] = 42
myNumbers[3] = 50
```

**Getting the array size**
```
int myNumbers[] = {25, 50, 75, 100}; 
printf("%zu", sizeof(myNumbers)); 
// This returns 20, we learned in the data type challenge that an int type is 4 bites so 4 bites x 5 elements.
```

**Getting the number of elements**
```
int myNumbers[] = {10, 25, 50, 75, 100};
int numElements = sizeof(myNumbers)/sizeof(myNumbers[0]);
printf("%d",numElements); //prints 5
```

**Looping through arrays**
```
int myNumbers[] = {10, 25, 50, 75, 100};
int length = sizeof(myNumbers)/sizeof(myNumbers[0]);

for(i = 0; i < length; i++){
	printf("%d\n", myNumbers[i]);
}
```

**Multidimensional**
```
int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };  // 2 rows, 3 columns 

int i, j;  //this needs to be  declared
for (i = 0; i < 2; i++) {  
  for (j = 0; j < 3; j++) {  
    printf("%d\n", matrix[i][j]);  
  }  
}
```
