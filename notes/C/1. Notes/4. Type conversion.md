	Type conversion is used when having to convert from a data type to another.

There are two types of conversion in C:

- **Implicit Conversion** (automatically)  
    
- **Explicit Conversion** (manually)     

**Implicit** 
The compiler automatically converts the type for you. There is risk of loss of information.

```
float x = 9;      // int → float
int x = 9.99;     // float → int → 9  (information was lost)
```

**Explicit (Casting)**
We explicitly specify the type

**Manual** — specify the type using `(type)`.

```
float x = (float)5 / 2;
// Result: 2.5
```

No casting:
```
float x = 5 / 2;
// Result: 2.0 because `5 / 2` is calculated as **integer division first**.
```

With casting:
```
float x = (float)5 / 2;
// Result: 2.5 because `(float)5` makes the division floating-point.
```

**Example**
```
int maxScore = 500;
int userScore = 423;

float percentage = (float)userScore / maxScore * 100.0;

printf("%.2f", percentage);
```
