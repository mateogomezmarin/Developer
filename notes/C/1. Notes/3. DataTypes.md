	A variable in C must be a specific data type and must use a format specifier inside printf()
```
// Create variables  
int myNum = 5;             // Integer (whole number)  
float myFloatNum = 5.99;   // Floating point number  
char myLetter = 'D';       // Character  
  
// Print variables  
printf("%d\n", myNum);  
printf("%f\n", myFloatNum);  
printf("%c\n", myLetter);
```

**Basic Data Types**

| Data Type |         Size | Description                                        | Example |
| --------- | -----------: | -------------------------------------------------- | ------- |
| `int`     | 2 or 4 bytes | Whole numbers without decimals                     | `1`     |
| `float`   |      4 bytes | Fractional numbers; ~6–7 decimal digits            | `1.99`  |
| `double`  |      8 bytes | Fractional numbers; ~15 decimal digits             | `1.99`  |
| `char`    |       1 byte | A single character, letter, number, or ASCII value | `'A'`   |
**Basic Format Specifiers

| Format Specifier | Data Type | Example   |
| ---------------- | --------- | --------- |
| `%d` or `%i`     | `int`     | `1`       |
| `%f`             | `float`   | `1.99`    |
| `%lf`            | `double`  | `1.99`    |
| `%c`             | `char`    | `'A'`     |
| `%s`             | String    | `"Hello"` |

> **Note:** Always use the correct format specifier for the corresponding data type. Using the wrong specifier can cause errors or undefined behavior.

**Scientific Numbers**
In C, you can write very large or very small floating-point numbers using scientific notation.
This is done using the letter `e` (or `E`), which stands for "times 10 to the power of".

**Set decimal precision**
A dot (`.`) followed by a number that specifies how many digits that should be shown after the decimal point:
```
float myFloatNum = 3.5;  
  
printf("%f\n", myFloatNum);   // Default will show 6 digits after the decimal point  
printf("%.1f\n", myFloatNum); // Only show 1 digit  
printf("%.2f\n", myFloatNum); // Only show 2 digits  
printf("%.4f", myFloatNum);   // Only show 4 digits
```

**Get the Memory Size**
We use the `sizeof()` operator:
```
int myInt;  
float myFloat;  
double myDouble;  
char myChar;  
  
printf("%zu\n", sizeof(myInt));  
printf("%zu\n", sizeof(myFloat));  
printf("%zu\n", sizeof(myDouble));  
printf("%zu\n", sizeof(myChar));
```

>Note that we use the `%zu` format specifier to print the result, instead of `%d`. This is because the compiler expects the `sizeof` operator to return a value of type `size_t`, which is an [unsigned integer type](https://www.w3schools.com/c/c_data_types_extended.php). On some computers it might work with `%d`, but it is safer and more portable to use `%zu`, which is specifically designed for printing `size_t` values.

Besides the basic types (`int`, `float`, `double`, `char`), C also gives you **extended keywords** (`short`, `long`, `unsigned`) to control how large the number is, or whether it can be negative.
