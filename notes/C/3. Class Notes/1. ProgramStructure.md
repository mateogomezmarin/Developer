This example demonstrates how a C program can be divided into **multiple `.c` files**.

The program consists of:

- `programStructure1.c` → contains the global array and function implementations.
- `programStructure2.c` → contains `main()` and uses the variables/functions defined in `file1.c`.


**What is the preprocessor?**

When you compile a C program:
```
gcc program.c
```
there are several stages involved.

A simplified view is:

```
program.c
   │
   ▼
Preprocessor
   │
   ▼
Expanded C code
   │
   ▼
Compiler
   │
   ▼
Machine/Object code
```

The **preprocessor runs before the compiler**.

It handles things such as:

- `#include`
- `#define`
- `#ifdef`
- `#ifndef`
- `#if`
  
  
  
  
  

```
#include <stdio.h> //Includes standard library

#define SIZE 5 //It tells the C preprocesor: whenever you see SIZE in the code write 5

/* Global variable */
int table[SIZE]; /*This creates an array of integers that when run through the C preprocesor has size 5. Array with size 5

┌────┬────┬────┬────┬────┐
│  0 │  0 │  0 │  0 │  0 │
└────┴────┴────┴────┴────┘
  0    1    2    3    4 	*/  
  

/* Function definition */
void fill_in(int *t, int size)  // *t is a pointer to an adress
{
    for (int i = 0; i < size; i++)
    {
        t[i] = i;
    }

    return;
}

/* Function definition */
void print_array(int *t, int size)
{
    for (int i = 0; i < size; i++)
    {
        printf("Array[%i] = %i\n", i, t[i]);
    }
}
```
